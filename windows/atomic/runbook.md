# Atomic Red Team на Windows-ВМ (ИЗОЛИРОВАННАЯ ЛАБОРАТОРИЯ)

> **Статус:** НЕ ПРОВЕРЕНО. Нет Windows-ВМ. Только для изолированной среды,
> без доступа в интернет с атакующей машины. Не запускать на рабочей системе.

## Подготовка
- Windows 10/11 ВМ, изолированная сеть.
- Sysmon установлен с фрагментом `windows/sysmon/sysmon-config-fragment.xml`.
- Wazuh Agent установлен, `ossec.conf` содержит `<localfile><log_format>eventchannel</log_format>...`.
- Atomic Red Team: `Install-AtomicRedTeam` (см. официальную документацию).

## Безопасные тесты (только эти)
- **T1059.001** (PowerShell): `Invoke-AtomicTest T1059.001 -TestNumbers 1`
- **T1136.001** (создание локального пользователя): `Invoke-AtomicTest T1136.001 -TestNumbers 1`
- **T1070.001** (очистка журнала): `Invoke-AtomicTest T1070.001 -TestNumbers 1` — **осторожно**, чистит журнал; делать **последним**.

## Ожидаемые алерты (НЕ гарантия)
- T1059.001 → 100220 (если процесс из Temp) или встроенные правила PowerShell (4104).
- T1136.001 → 100230 (4720).
- T1070.001 → 100240 (1102).

Проверять через `wazuh-logtest` и живой поток. Пока не проверено — в README «не проверено».
