# Плейбук L1: Port Scan (Recon)

## Триггер
Правило Wazuh/socsim: **100120** (много DROP за короткое время).

## Что видим в логах
- Множество `kernel: [IPTABLES DROP] ... DPT=<разные порты>`.
- Один IP источник.

## Шаги триажа L1
1. Проверить IP. Если `198.18.x.x` — это легитимное сканирование (Nessus). False Positive.
2. Если IP внешний — оценить масштаб (сканируется 1 порт или все подряд).
3. Проверить, есть ли после сканирования успешные подключения (Accepted) с этого IP.

## Действия
- Заблокировать IP на периметре.
- Уведомить сетевую команду.
