# Плейбук L1: SSH Brute Force / Compromise

## Триггер
Правила Wazuh/socsim: **100100** (SSH brute force) и **100101** (SSH compromise).

## Что видим в логах
- Много строк `Failed password for <user> from <IP>`.
- Затем `Accepted password for <user> from <IP>`.

## Шаги триажа L1
1. Проверить, не является ли IP `198.18.x.x` (легитимный сканер/пентест). Если да — False Positive.
2. Проверить пользователя. Если это сервисная учетка с опечаткой — False Positive.
3. Если IP атакующий (документационный) и вход успешный — эскалация.
4. Проверить, что делал пользователь после входа (команды, создание файлов).

## Действия
- Заблокировать IP на фаерволе.
- Запросить сброс пароля у пользователя.
- Изолировать хост при подозрении на компрометацию.
