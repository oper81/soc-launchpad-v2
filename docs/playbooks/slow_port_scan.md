# Плейбук L1: Slow Port Scan (Evasive)

## Триггер
В текущей версии правил **алерта нет** (демонстрация слепой зоны).
Этот плейбук описывает, как действовать, если мы найдем такие события
вручную (например, при проактивном поиске угроз).

## Что видим в логах
- Редкие `IPTABLES DROP` с одного IP, раз в 10-15 минут.
- Сканирование растянуто по времени, чтобы обходить пороги.

## Шаги триажа L1
1. Обнаружить аномалию вручную (например, по графику частоты DROP).
2. Проверить историю IP за неделю.
3. Проверить, не было ли за этим IP других атак.

## Действия
- Заблокировать IP.
- Предложить обновление правил (добавление длинных окон корреляции или анализ baseline).
