# Плейбук L1: Valid Account After Hours

## Триггер
Правило Wazuh/socsim: **100140** (успешный вход в нерабочее время, 00:00-06:00).

## Что видим в логах
- `sshd: Accepted password for <user>` в 2-4 часа ночи.

## Шаги триажа L1
1. Связаться с пользователем (если это внутренний сотрудник).
2. Проверить, есть ли у него ночные смены или плановые работы.
3. Проверить источник IP. Если это внешний IP (не из `198.18.x.x`) — подозрительно.
4. Проверить, что делал пользователь после входа (эскалация привилегий, создание файлов).

## Действия
- При подтверждении подозрений — заблокировать аккаунт и запустить расследование.
